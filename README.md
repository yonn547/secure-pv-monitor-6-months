# Secure PV Monitor: 6-Month OT Security & Automation Journey

## 🎯 Visi
Membangun sistem monitoring Pembangkit Listrik Tenaga Surya (PLTS) yang aman dari tingkat protokol (Modbus/OPC UA) hingga deteksi anomali, sebagai fondasi menuju analisis infrastruktur Web3/Crypto (DePIN/RWA).
